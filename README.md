# 🎧 PodcastTimePredictor-AI

A simple machine learning model that predicts the duration of a podcast episode based on its title and description.

## Features
- Input: Podcast title + description
- Output: Predicted duration in minutes
- ML model: Ridge Regression with TF-IDF vectorization
- Built using: Python, Scikit-learn, Pandas

## How to Run
```bash
pip install -r requirements.txt
python predictor.py
```

## Example Prediction
> Title: The Future of AI  
> Description: Insights into upcoming AI tools and trends  
> **Predicted Duration: ~20 mins**
